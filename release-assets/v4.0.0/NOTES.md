# Dot Home 4.0.0

A rebuilt offline launcher using a pinned Launcher3/Lawnchair workspace in place of the earlier custom engine.

- Native paging, drag/reorder, folders, resize and swipe-up Apps drawer; compact Home actions and separate customisation/settings screens.
- Bundled monochrome icon mappings, circle masks, installed icon packs and enlarged icons/folders.
- Independent light/dark and Classic/Translucent/Dynamic appearance; original local wallpapers, image crop and actual Home previews.
- Provider-organised widget tray, working local widget artwork and per-instance clock faces/colours. Select a widget in Arrange, then tap Style.
- Batch app/widget selection, group dragging, page movement, folders, covers and local layout backup/restore.
- Original package, Home component and signing identity retained. Existing v3 layouts are imported into the native database; the old JSON and a recovery copy are kept.

No Internet permission, network client or online option. No Accessibility service, global gesture overlay, root or secure-settings navigation feature. Optional calendar, flashlight, usage and media access is requested only when relevant; normal Home/Apps does not need those grants.

Install the APK over the existing app, open Dot Home and choose it as the default Home application. Android 15 or newer is required. Android owns system Home/Back/Recents and navigation gestures; manufacturer restrictions cannot be removed by an ordinary launcher. Keep your stock launcher installed.

This is an independent Nothing-inspired launcher, not Nothing OS firmware or a pixel-perfect proprietary launcher port. Lock screen, notification shade, Quick Settings, Glyph hardware and cloud/Essential features remain outside the app. External widget providers and photos retain their own permission/reconnection requirements.

The attached APK is signed locally with the original certificate. Publication verifies its checksum and signature and compares every APK payload entry with the successful GitHub Actions release artifact. The private signing key is never uploaded.
